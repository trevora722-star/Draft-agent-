Appendix — Methodology

QAgent crawls the target from the base URL (BFS, same-origin, depth-limited), captures DOM inventories and screenshots, and runs a test battery (when present) covering accessibility (axe-core), performance budgets, basic security headers, and visual smoke checks. Raw observations are written as findings; the intelligence pass deduplicates them into bugs, recalibrates severity with Claude Opus 4.7, and produces this report.
